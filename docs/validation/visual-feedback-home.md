# Validação visual — feedback nos destinos da Home

Data: 2026-08-29

A Home foi conferida em viewport desktop (1280×720, página completa) e móvel (375×812, página completa). Os cartões de destinos exibem o acionador `Feedback` junto às ações existentes, mantendo a hierarquia visual e o padrão de cores do protótipo. No móvel, os cartões se reorganizam em coluna, os acionadores permanecem legíveis e não foi observado overflow horizontal. A janela contextual foi implementada para abrir sobre a página, identificar o destino selecionado e manter o envio demonstrativo sem armazenamento de dados pessoais.
